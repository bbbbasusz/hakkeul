학글(Hakkul) 변환 규칙 안내

입력 방식

자동 감지: â, chh, 하이픈, p/t/k 받침 등 교회식 특징을 실시간 감지
교육부 (MoE): 臺灣客家語拼音方案 그대로 입력
교회 (PFS): Pha̍k-fa-sṳ → 교육부식 변환 후 한글 파이프라인
예: thai-kâ → taiˋgaˊ(하이픈 붙여 씀) → 한글
교회 o[a|e] = 교육부 u[a|e] · 교회 종성 p/t/k → b/d/g

3단계 파이프라인

  1. vars : 로마자 → 키릴 중간 표기 (환경 {} 반영, 긴 것 우선)
  2. rewrite : 음운 재쓰기 · [к|г]вє[к|т]→[к|г]ўи[к|т]
  3. transcribe : 키릴 → 한글 초·중·종성 후 합성

음절말 자음 규칙

교육부 종성: b d g m n ng · 교회식 종성: p t k(내부적으로 b/d/g로 정규화).
허용 음절 구조(СГ, СГС, Г, СПГ, СПГС, ПГ) 외의 패턴(외국어 등)은 변환하지 않고 원문 그대로 둡니다.
모음 뒤에 나온 일반 자음이 초성을 덮어쓰지 않습니다. (예: sat → 사, bul → 부)

음절 자음 (m n ng)

앞에 모음이 없으면 М → 모, Н → 니, Ң → ᅌᅩ 로 변환됩니다.

r / rh / f / v 처리

rh → ж → й, r → 〻 → њ (ㅿ), Ж → њ
фи → пуй, ф/@ → пў, ви → уй, в/@ → ў

성조 · 경음화 (방언 선택)

사현: ˊ/ˇ → (무), ˋ → 〯, ˉ → 〮 · 경음: ˇ+(개방/비음), ˉ+(입성)
해륙: ˋ/ˉ → (무), ˊ → 〯, ˇ/⁺ → 〮 · 경음: (ˉ|⁺)+(개방/비음), ˋ+(입성)
